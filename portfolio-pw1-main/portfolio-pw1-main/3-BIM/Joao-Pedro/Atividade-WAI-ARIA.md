# Questão 1
Nos dias atuais onde a internet e seus sites são fundamentais na vida de milhares, acessibilidade também tem de estar presente nessa constante evolução, o WAI-ARIA faz exatamente isso, torna aplicações web mais acessíveis a pessoas com deficiências, como pessoas que dependem de leitores de tela e pessoas que não podem usar um mouse, além de definir maneiras de fornecer funcionalidades para usuarios com deficiência. Sem o WAI-ARIA, certas funcionalidades usadas em sites não estão disponíveis para alguns usuários com deficiência. 
# Questão 2
**A)** O aria-controls informa qual elemento da página é controlado por um  botão.

**B)** O atributo aria-expanded informa se o elemento controlado está expandido ou recolhido. Isso permite que usuários de tecnologias assistivas saibam o estado atual do menu.

**C)** O aria-label identifica elementos sem textos visíveis e fornece uma descrição acessível para o elemento quando seu texto visível não é suficiente para explicar sua função.

# Questão 3
O HTML já fornece o significado e estruturas para os elementos de tal página. As tags como button, nav, main são reconhecidas naturalmente, ele já fornece tal acessibilidade. Quando o HTML semântico não for suficiente para descrever corretamente um comportamento, o WAI-ARIA deve ser utilizado. Um exemplo é quando se tem o uso de um menu suspenso com div e JavaScript, já que esses elementos não possuem um significado semântico, o uso do WAI-ARIA é indispensavel paara informar aos leitores de tela que se trata de um menu.
