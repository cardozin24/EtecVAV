História do Bootstrap

Conheça a origem e a evolução do framework.

Origem

O Bootstrap foi criado por desenvolvedores que trabalhavam no Twitter. A ferramenta surgiu para ajudar a padronizar os elementos das interfaces utilizadas nos projetos da empresa.

Lançamento

O projeto foi lançado publicamente em 2011. Com o tempo, tornou-se bastante utilizado por desenvolvedores devido à facilidade para criar páginas organizadas e responsivas.

Evolução

Ao longo dos anos, o Bootstrap recebeu novas versões, componentes, melhorias de responsividade e recursos para facilitar o desenvolvimento de páginas modernas.
