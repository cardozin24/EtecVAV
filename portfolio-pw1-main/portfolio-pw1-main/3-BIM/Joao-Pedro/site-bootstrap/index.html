O que é Bootstrap?

Bootstrap é um framework front-end utilizado para facilitar a criação de páginas web. Ele possui classes, componentes e ferramentas que ajudam no desenvolvimento de sites.

Responsivo

Adapta o site para computadores, tablets e celulares.

Prático

Possui diversos componentes prontos para facilitar o desenvolvimento.

Organizado

Utiliza classes que ajudam na organização do código.
