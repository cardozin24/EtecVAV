Utilidades do Bootstrap

Veja onde o Bootstrap pode ser utilizado.

Principais utilidades

Grid

Organiza os elementos da página utilizando linhas e colunas.

Botões

Permite criar botões com diferentes cores e estilos.

Cards

Organiza informações em blocos visuais.

Menus

Facilita a criação de barras de navegação responsivas.

Alertas

Exibe mensagens de informação, sucesso ou aviso.

Modais

Cria janelas que aparecem sobre o conteúdo da página.

Exemplos

O Bootstrap pode ser utilizado em sites, sistemas, portfólios, lojas virtuais, páginas institucionais e diversos outros projetos.
