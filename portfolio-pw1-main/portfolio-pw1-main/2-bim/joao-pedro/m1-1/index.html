CSS

Seletores, propriedades e valores

Seletores

Em CSS, os seletores são usados para direcionar os elementos HTML em nossas páginas da web que queremos estilizar.
Há uma grande variedade de seletores CSS disponíveis, permitindo uma precisão refinada ao selecionar os elementos a serem estilizados.
Você já conheceu os seletores. Um seletor CSS é a primeira parte de uma regra CSS. É um padrão de elementos e outros termos que informam
ao navegador quais elementos HTML devem ser selecionados para que os valores de propriedade CSS dentro da regra sejam aplicados a eles.
O elemento ou elementos que são selecionados pelo seletor são referidos como o assunto do seletor .

Propriedades

Uma propriedade do CSS é um parâmetro usado em uma declaração CSS que permite estilizar certos aspectos de elementos selecionados.
Por exemplo, a propriedade é usada para definir a opacidade de um elemento selecionado, permitindo controlar se o conteúdo atrás desse elemento está visível.
Cada propriedade tem um nome (por exemplo, "position: absolute" opacity), um valor (por exemplo, "position: absolute" 0.8)
e um comportamento definido na renderização do documento. O CSS também define propriedades abreviadas, permitindo especificar várias propriedades relacionadas em uma única declaração.

Valores

Valores CSS definem as características de estilo (cores, tamanhos, posições) aplicadas a elementos HTML,
podendo ser absolutos (como px, pt) ou relativos (como em, rem, %). Eles incluem tipos como números,
comprimentos, porcentagens, cores, e palavras-chave, essenciais para o design responsivo

Principais tipos de valores do CSS

Unidade de medida e comprimento

  • Absolutas: Fixas, como pixels (px), pontos (pt), ou centímetros (cm). Ideais para tamanhos precisos como bordas.
  • Relativas: Escalam conforme o contexto, incluindo %, em (relativo ao tamanho da fonte do elemento) e rem (relativo ao elemento raiz).
  • Viewport: vw (1% da largura da tela) e vh (1% da altura da tela).

Cores

  • Nome: Nomes pré-definidos como red, blue, transparent.
  • Hexadecimal: #000000 (preto) a #FFFFFF (branco).
  • RGB/RGBA: rgb(0, 0, 0) ou rgba com canal alfa para transparência.
  • HSL/HSLA: hsl(120, 100%, 50%) (matiz, saturação, luminosidade).

Palavras Chave comuns

  • herança: inherit (força a herança do pai).
  • inicial: initial (define o valor padrão do navegador).
  • display: block, inline, flex, grid, none.
  • posicionamento: static, relative, absolute, fixed, sticky.

Valores funcionais

  • url('imagem.jpg'): Para carregar fundos ou fontes.
  • calc(): Para realizar cálculos simples de layout, ex: width: calc(100% - 20px);.
