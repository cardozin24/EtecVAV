O Surgimento da Internet

Tudo começou com a ARPANET em 1969. Criada pelo Departamento de Defesa dos EUA, ela foi a primeira rede a usar a comutaçao de pacotes, permitindo que computadores "conversassem" mesmo se partes da rede estivessem fora do ar.

A Criaçao do HTML

O HTML (HyperText Markup Language) foi criado em 1989. Diferente do que muitos pensam, ele nao e uma linguagem de programaçao, mas sim de marcaçao. Sua funçao original era permitir que pesquisadores do CERN compartilhassem relatorios cientificos atraves de links clicaveis.

Exemplo de Estrutura HTML

O HTML utiliza "tags" para organizar o conteudo:

  • H1: Define o titulo principal.
  • P: Define os paragrafos de texto.
  • A: Cria os links de navegaçao.
